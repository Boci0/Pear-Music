## v3.4.5 (2026-09-13)

## Overview
Pear Music v3.4.5 resolves queue state synchronization, isolates concurrent streaming discovery requests, and hardens visualizer wake behavior.

## Key Changes
* **Queue State Synchronization:** Synchronized `queueIndex` dynamically with active track identity across player mutations (`playNext`, `addToQueue`, `addSongsToQueue`, `reorderQueue`, `removeFromQueue`, and `previous`).
* **Streaming Discovery Isolation:** Added request token and seed identity verification to background track recommendations and queue re-rolls. In-flight network tasks for superseded tracks are automatically discarded.
* **Queue and Peek Bar Highlighting:** Updated queue list views, peek headers, and side drawers to highlight the active song using song ID identity checks rather than fragile raw array index offsets.
* **Visualizer Wake Protection:** Ensured audio visualizer processing restarts cleanly without UI freezes when resuming playback after a sleep timer expiration.

## Music (2026-08-10)

## Pear Music 1.0.0

Peer-to-peer music sync for Windows and Android. No cloud, no accounts. Pair
two devices with a code, add a song on one, and every paired device gets a copy.
Works entirely on your own network, even a phone hotspot with no internet.

#### Features
- Zero-config connection: devices find each other automatically, no server setup
- Smart host switching: the last online device hosts and takes over in seconds
- Code + QR pairing between devices
- End-to-end encrypted sync (X25519 + AES-256-GCM)
- Auto catch-up: when a paired device reconnects, it gets anything it missed
- Two-way playlist sync
- YouTube / Spotify link downloads
- Full media notification controls on Android
- Unpair removes the shared songs that device received from you
- Works as a standalone local music player

#### Requirements
- Both devices on the **same network** (Wi-Fi or a phone hotspot)
- Windows: allow Pear Music through the firewall (it uses port 8080)
- Android: allow installing apps from unknown sources

#### Downloads
- Windows: `PearMusic-Windows-x64.zip` (extract, then run `peerm_app.exe`)
- Android: `PearMusic-Android-arm64.apk` (most phones) or `PearMusic-Android-armv7.apk` (older devices)

**Full Changelog**: https://github.com/Boci0/Pear-Music/commits/Music
